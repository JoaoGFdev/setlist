# Playlist Bridge

A personal music workbench: two libraries lead into a shared track-by-track transfer workspace. The user owns the credentials and runs it locally; no billing or artificial song cap.

Palette: paper white #f6f8fb, deep blue #163d67, ink #182c42, muted blue #62758a, Spotify green #197447, YouTube red #bf383d. System Avenir Next/Trebuchet sans for familiar music-library density, Georgia only for the product title. Left aligned lists, compact controls, ample space around the active transfer. The memorable element is the two-sided library connected by a simple bridge graphic, not decorative dashboard metrics. No external fonts or image assets needed.

The initial layout idea was a generic pair of account cards. Revised to continuous library panels: connection controls live directly above each service's playlists. Errors explain the next action; unavailable services remain usable independently.
